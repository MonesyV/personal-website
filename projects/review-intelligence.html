Case file 03 · Review intelligence

电商评论情感分析与风险处置 Agent

本地情感小模型负责高频判断，确定性规则守住安全底线；低置信度和复杂表达才进入可选 LLM 回退，高风险评论直接升级人工。

场景
电商评论分析与风险分流
模型
BERT 教师 · BiLSTM 学生
服务
FastAPI · PostgreSQL
状态
CPU 小样本工程试跑
情感告诉你用户的态度；风险规则决定什么必须先处理。

“电池充电时冒烟”即使被量化模型判断为中性，也不能进入普通统计队列。系统把情感识别与风险判断分离，让起火、伤害、支付和隐私等信号绕过模型置信度，直接进入人工处置路径。

  • Knowledge Distillation
  • INT8
  • Safety Rules
  • LLM Fallback
  • HITL

Action ladder

风险等级不是标签装饰，而是处置入口。

规则选择最高风险级别，并把结果映射到明确动作；High 与 Critical 均要求人工介入。

LOW普通评价记录观察
MEDIUM物流、包装、客服等问题客服跟进
HIGH电池、退款、隐私、支付风险高优工单 · 人工介入
CRITICAL起火、爆炸、触电、伤害、疑似假货立即人工复核

Decision pipeline

先本地判断，再按风险与不确定性分流。

INPUT

类型化输入

Pydantic 校验评论文本与 review_id，空文本直接拒绝，统一单条分析请求结构。

LOCAL MODEL

情感小模型

默认加载剪枝 INT8 BiLSTM，输出 positive / neutral / negative 与置信度。

SAFETY RULES

确定性风险路由

独立规则扫描安全、退款、隐私、支付等信号，最高等级决定业务动作。

FALLBACK

语义回退与持久化

低置信度或复杂文本可调用 DeepSeek；结果校验后与本地结论合并，并按 review_id 写入 PostgreSQL。

Controlled fallback

外部模型是补充路径，不是安全裁判。

01

默认关闭

LLM 回退必须通过环境变量显式启用；基础服务可以只依赖本地模型与规则运行。

02

按不确定性触发

默认置信度阈值为 0.85；长文本、多主题、反讽与复杂否定也可进入语义回退。

03

高风险不等待

本地规则判定为 High 或 Critical 时直接保留人工升级路径，不等待外部模型响应，也不允许语义结果降级风险。

04

失败保持本地结论

外部调用或结构校验失败时记录错误类型，返回已完成的本地分析，不把上游故障扩散为接口不可用。

能力边界：这是可复现的小样本工程试跑，不是生产级风控模型。

MARC 星级被映射为三分类情感，其中 3 星作为 neutral 属于弱监督标签；正式训练还需要完整数据、更多轮次和专项风险样本。公开仓库包含训练脚本、配置、指标报告与验收代码，但不包含报告中生成的模型权重。数据使用还需遵守原始 Amazon Multilingual Reviews Corpus 条款。
